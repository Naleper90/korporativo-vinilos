# Galería de Trabajos Realizados

## Imágenes necesarias

Coloca aquí 5 imágenes con los siguientes nombres:

- `trabajo-1.jpg` - Rotulación corporativa
- `trabajo-2.jpg` - Decoración interior
- `trabajo-3.jpg` - Vinilo para cristaleras
- `trabajo-4.jpg` - Rotulación de vehículos
- `trabajo-5.jpg` - Decoración motivacional

## Especificaciones técnicas

- **Formato recomendado:** JPG o WebP
- **Tamaño recomendado:** 800-1200px de ancho
- **Aspect ratio:** 4:3 (ejemplo: 800x600px, 1200x900px)
- **Peso máximo:** 200-300KB por imagen (optimizadas)

## Accesibilidad

Cada imagen ya tiene configurado:
- `loading="lazy"` para carga diferida
- `alt` descriptivo (puedes personalizar en `home.html`)
- `width` y `height` para evitar layout shift
- `<figcaption>` con descripción visible

## Personalización

Si quieres cambiar los textos:
- **Alt text:** Editar en `frontend/src/app/pages/home/home.html`
- **Caption:** También en el mismo archivo, dentro de `<figcaption>`
